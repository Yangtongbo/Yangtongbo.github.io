RAG / LLM APPLICATION

DocMind

Enterprise Document Intelligence & RAG Platform

面向企业文档知识库的智能问答系统，支持从文档接入到检索增强生成、权限控制与效果评测的一体化流程。

  • PDF、Word、Markdown 文档解析、切片、向量化与增量更新
  • 关键词 + 向量混合检索，并结合重排序提升召回质量
  • 支持多轮问答、原文引用与无依据回答拒答
  • 知识库隔离、用户权限与操作审计
  • 提示词注入防护与敏感信息过滤
  • 在线模型 / 本地模型自由切换
  • 评测 RAG 召回率、回答忠实度与响应时间

AI DETECTION / REAL-TIME SYSTEM

SentinelFlow

Intelligent Anomaly Detection & Observability Platform

面向日志、接口指标、交易数据与传感器时序数据的异常检测平台，将实时数据处理、机器学习检测与大模型分析结合。

  • 实时数据接入、清洗与滑动窗口处理
  • Isolation Forest、XGBoost、Autoencoder 多模型对比
  • 异常评分、告警聚合与误报抑制
  • 使用 SHAP 解释异常原因和关键特征贡献
  • 大模型自动生成异常摘要与处置建议
  • 模型版本管理、在线推理和效果监控
  • 评测 F1、误报率、检测延迟、吞吐量与 P95
